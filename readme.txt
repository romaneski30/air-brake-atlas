AIR-BRAKE VISUAL ATLAS

Website: https://air-brake-atlas.pages.dev

PURPOSE
A visual learning reference for understanding tractor-trailer air brakes.
Color-coded paths are placed on a recognizable vehicle diagram and revealed
in layers, making the sources, controls and brake actions easier to follow.

VIEWS
1. Make and store compressed air.
2. Use stored air for tractor service and spring/parking brakes.
3A. Trailer supply and service braking.
3B. Independent hand control and command selection.
4. All taught systems together.

HOW IT WORKS
The page uses HTML, CSS, JavaScript and embedded SVG diagrams. GitHub stores
the project and its revision history; Cloudflare Pages hosts the website.
The browser runs the interactive controls. The QR code shares the website
address, not personal notes.

NOTES
Notes remain while the page is open. They are not autosaved or synchronized
between devices. The page supports downloading and restoring notes manually.

DEVELOPMENT
Created through iterative visual design, technical questions, diagram review
and testing, with AI assistance in implementation and automated validation.

SCOPE
This is a proportioned educational schematic, not exact vehicle piping or a
repair manual. Some equipment and connections are simplified or hidden.
Service air applies braking; removing spring holding air allows the spring
to apply. Follow qualified instruction and the vehicle's documentation.
Never dismantle a spring-brake chamber to experiment with these concepts.
